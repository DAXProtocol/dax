Protocol Engine · 4-Stage Settlement Lifecycle

CREATE · ESCROW · EVIDENCE · RESOLVE

DAX replaces human middlemen and centralized custodial risk with an automated EVM state machine running on Arbitrum One:

STAGE 01
CREATE
Bilateral or open-invitation agreement created. Terms, milestones, and deadlines are cryptographically bound via EIP-712 typed data signatures (`termsHash`).
STAGE 02
ESCROW
Stablecoins (USDT, USDC, ARB, ETH) locked directly in `DAX_AgreementUpgradeable.sol`. Zero admin keys, zero server custody. Funds unlock only on satisfaction.
STAGE 03
EVIDENCE
Work deliverables, bills of lading, or receipts are fingerprinted client-side with SHA-256 and committed as immutable Merkle roots on-chain.
STAGE 04
RESOLVE
Disputed escrows automatically escalate to `DAX_Court.sol`. Staked community jurors vote using a commit-reveal Schelling-point game with slashing for corruption.
Secret Sauce · Zero-Leak Security & Mechanism Design

Hardware-Grade Security Meets
Game-Theoretic Community Justice

Four proprietary architectural layers that protect users against surveillance, fund seizure, bribery, and fraud:

🛡️
Pure AndroidX Biometrics

Hardware-backed `BIOMETRIC_STRONG` gate with 0 fallback to OS passcodes. Keys derived inside isolated memory using BIP-39/44 and stored in Android Keystore AES-GCM.

🔒
Dynamic Screen Privacy

Runtime `FLAG_SECURE` integration blinds OS task switcher previews and blocks screenshots whenever private keys, seed phrases, or sensitive agreements are active.

⚖️
Anti-Bribery Schelling Court

2-phase commit-reveal voting (`keccak256(vote + salt)`) prevents vote-buying and bandwagoning. Malicious jurors are economically slashed; honest jurors earn dispute fees.

⚡
Sub-Cent L2 Execution

Natively optimized for Arbitrum One with sub-cent gas fees and instant L2 finality, making micro-agreements and small escrows ($10–$500) frictionless and highly profitable.
